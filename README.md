# RespiraDom — Healthcare Activity Analysis with Power BI
Comparative analysis of healthcare activity across two agencies: Lyon and Bordeaux.

## Project Overview
This project explores healthcare activity in Lyon and Bordeaux, comparing intervention volumes, service distribution, and completion rates using Power BI.

## Objectives
- Compare patient and intervention volumes.
- Analyse the distribution of healthcare services.
- Compare completed and cancelled interventions.
- Present key findings through data visualisations.

## Tools
Power BI, data visualisation, comparative analysis.

## Key Findings
- Lyon recorded 362 interventions, compared with 258 in Bordeaux.
- The distribution of healthcare services differed between the two agencies.
- The completion rate was 72.1% in Lyon and 75.6% in Bordeaux.

## Analytical Limitation
Differences in activity volumes alone do not establish which agency performs better. Additional indicators and time-based analysis would be needed.
